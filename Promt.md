Напиши C# Minimal API проект

* Проект при своём старте должен загружать "primitives.json". Это исходная информация которая будет обрабатываться проектом.
* Структура исходных данных - это массив "Layer"
"type" - свойство слоя - это тип графического примитива, и соответствует такому enum

```C#
enum GrTypeEnum
{
    /**Линия */
    Line = 1,
    /** Полигон */
    Polygon = 2,
}
```

* Главная функция - это обработать загруженные данные и вернуть их в REST запросе
* Функция обязательно состоит из
  * Каждый "Layer" обрабатывается и отбрасывается слой, который удовлетворяет l.MashtabRange.Min > Mashtab || l.MashtabRange.Max < Mashtab, где Mashtab = 100
  * Если "Layer" имеет какой-то другой тип, не Line или Polygon, то этот слой игнорируется
  * Каждый primitive клипируется по описывающему прямоугольнику. Алгоритм клипирования Сазерланда-Ходжмана
  * клипирующий прямоугольник это прямоугольник с такими координатами { Left = 1200, Bottom = 50, Right = 4000, Top = 2850 }, обрати внимание что линия и полигон, клипируются немного по разному
  * оптимизируются координаты - удаляются точки которые минимально повлияют на внешний вид примитива, например если есть точка 1, 2, 3 и если провести прямую через 1 и 3, то если точка 2 находится на меньшем расстоянии от прямой чем 1/0.37037037037037035, тогда такая точка исключается из результата
  * после чего каждая координата "coord" преобразуются к экранным по формуле

```C#
scale = 0.37037037037037035;
 x /=100;
 y /=100;
 (left, top) = (1200 + x, 2850 + y);
 coord = ((xSource-left)*scale, (top - ySource)*scale);
```

* x и y - это аргумент Rest функции
* scale и left, top передаются в функцию преобразования в качестве аргументов
* Вычисляться должны все "Layer", результат помещается в коллекцию DTO
* REST функция возвращает только первые 5 "Layer" из вычисленной коллекции DTO
* Если передать x = 0 и y = 0, то расчёт должен соответствовать "result.json" по данным, без учёта форматирования json
* Форматировать результат не нужно, нужно что бы выходные данные соответствовали
* Нельзя кешировать действия главной функции, каждый вызов должен выполнять полную работу
